## 当前功能分支增量

本次核验时分支为 `feat/console-page-navigation`。仓库还存在不属于本轮功能的未跟踪官网与部署文件，后续 AI 不得重置、覆盖或误提交。当前分支在已部署 v0.9.8 控制端基础上新增：

- 节点管理的新增、编辑、证书、交付记录、安装命令及状态变更统一使用页面内对话框；异步旧响应不会污染新打开的节点，对修订冲突会要求基于最新节点重新确认。
- schema v39/v40 增加独立 Lightsail 实例/任务表、默认关闭配置、AWS adapter、临时 SSH runner、租约 worker、平台管理员 API 与 `#/lightsail` 页面。空脚本不开放 SSH，非空脚本最多一次且 `unknown` 不重放；云资源不会自动转成入口节点。控制端已部署并完成真实 AWS 只读区域/目录鉴权，尚未购买资源或验收 SSH 生命周期。
