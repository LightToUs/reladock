## 尚未实现或尚未完成环境验收

真实 VPS/容量验收、合作端到端协议探针、商户激活与人工对账流程、跨故障域备份保留及替换主机恢复演练、Redis 与后续企业组网。云厂商 API 自动购机/释放、按规则自动扩缩、备用资源编排、活动周期提前替换或排队续费也尚未实现；当前服务器继续人工采购和登记。内网穿透的客户内网网关、主动出站通道、公网端口到私网目标的映射、网关身份/撤权、重连、路由/ACL 及健康验收也尚未实现；已有通道使私网目标对入口节点可路由时的普通转发，不等于平台已具备主动内网穿透。加密包创建、控制临时数据库校验和节点仅暂存校验已实现，但不等于离机耐久性或 RPO/RTO 已验收。平台 retirement 状态机、schema-2 allocation-ID quarantine/回滚底座、固定 conntrack 执行器、复用 Pending/Recovery 的 Adapter 本地 purge journal/ACK 分类/原子 predecessor 接管、apply-only mTLS Agent 领取/begin/proof/report 恢复闭环，以及不可逆 draining 和最终节点身份撤销门禁已实现。管理界面已逐项显示退役门禁，Agent 安装和 apply 单元检查固定 conntrack-tools，发布清单仍保持 `productionReady=false`；生产式退役演练按 `docs/acceptance/SAFE_RETIREMENT.md` 尚未执行。Agent updater 已实现但尚未完成真实 VPS 上安装中断、健康超时、回滚失败及离机状态恢复演练；节点应用日志/WAL 丢失后的人工重建流程仍需专门运维验收，不能自动清屏障或重置计量。生产服务器/域名/支付渠道由用户之后确定。

## 实施顺序

1. 已具备账户、规则、节点、成员/Key、配置分发、钱包套餐和支付连接器基础；继续保持回归与审查。
2. 已组合 Agent、tc、应用互斥、删除确认与目标可达性；继续完成真实生产路由/协议验收及安全退役端口回收。
3. 已实现逐规则、逐周期 WAL、重置/补传和去重；完成真实 offload/重传/计量差异与容量验收，不建立企业共享额度。
4. 商业闭环验收：真实支付、退款与对账、套餐续期和超额处置。
5. 运营验收：合作外部协议探测、签名通知接收方、成本凭据核对、工单与离机恢复。已完成对应基础功能不等于运营环境已验收。
6. 现有 1 家 VPN 服务商试点：真实传输、真实订单与账单、续费验证。
7. 客户有订单时拓展内网穿透与企业组网；先验证单站点主动出站通道和 TCP/UDP 公网端口映射，再拓展多站点路由/ACL、多跳、上游防护、云骨干、专线和轻量 SD-WAN。

## 关键验收

统一执行步骤与证据格式见 `docs/acceptance/LINK_AND_CAPACITY.md`；清单已准备不等于任何生产线路已经通过。

- TCP/UDP/两者的传输、空闲重连、MTU、大包与小包 PPS。
- 端口竞争、规则修改、暂停既有流量、删除回收和配置失败回滚。

- 客户能完成付款、创建规则、收到入口、产生流量、看到账单并续费。
