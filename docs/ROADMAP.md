# 开发计划与交付状态

## 已实现

- v18 节点 bootstrap：后台一次性命令、短期凭证摘要/撤销与并发兑换、CSR 节点证书签发、本地密钥、GitHub 固定版本/摘要安装包、自动启动 validation、mTLS 环境报告。安装包尚未发布；真实 VPS/systemd、GitHub 可达性和长期证书轮换仍需验收/补齐，不视为生产就绪。

- Go HTTP 服务与真实 PostgreSQL 持久化，版本化事务迁移，独立本地数据库与数据卷。
- 企业开通、密码登录、24 小时会话、退出撤销及企业数据隔离。
- 规则参数校验、数据库约束的 TCP/UDP 端口预留、并发分配、创建幂等、配置暂停和删除。
- 规则期望版本、未交付状态与企业操作审计，不模拟节点在线或真实转发。
- 登录/规则页面接入真实 API，同源保护、输入限制、单进程限流。
- 节点运维 CLI（登记、维护、证书绑定与轮换、交付重试）、节点列表与入口选择、规则恢复。
- 规则变更的事务 Outbox、全节点版本化快照与 checksum、租约领取、失败退避、过期回收及重复/陈旧回报处理；v1 无损升级回填。
- 独立 mTLS Agent 通道、默认校验模式与显式 Linux 应用模式；持久交付 journal、applying 屏障、已核对的安全失败和 applied ACK，仍不标记端到端健康。
- 全平台后台 `/admin`：独立平台权限、节点新增/编辑/维护/证书绑定和撤销/配置重试，企业分页与登录停用/恢复、全局规则筛选与跨企业操作、交付记录、平台操作审计。
- v3 迁移、CLI 显式授权/撤销与会话清除、平台写权限数据库核验、事务审计、节点/企业/规则版本冲突保护。企业 owner 不具备全局权限。
- 真实 PostgreSQL 集成测试：端口竞争、越权、幂等冲突、事务回滚、会话生命周期及 HTTP 安全边界，支持竞态检测。
- 邮箱绑定邀请、成员角色、Key 范围/到期/撤销及 HTTP 与事务内权限复核，网页已接入。
- 每规则独立用量接收、epoch/sequence 去重、不可变账本、整数钱包、显式套餐版本、购买/续购和配额暂停请求。付费流量明确绑定周期，迟到报告不占用新周期额度。
- 控制通道告警去重与工单、可选且默认关闭的 Stripe 支付连接器，已接入真实数据库与替身支付接口测试；无真实商户收款。
- 告警转移同事务通知 Outbox、默认关闭的签名 HTTPS webhook、有界租约/重试、后台通知交付及耗尽后人工重试；不假装通知已读。
- 不可变节点成本、发票/请求幂等与事务审计、按实际套餐扣费和已录成本的现金口径差额。成本缺失保持未知，不推测企业成本归属或应计毛利。
- 生产 HTTPS、数据库共享限流、Linux 构建及按组件安装模板；独立应用服务不自动启用。隔离 Docker 实测组合 TCP/UDP、逐规则 tc、全包计数/WAL、额度耗尽、替换不重置额度、Agent 离线内核到期和失败回滚。v0.7.8 增加 iproute2 5.15 HTB class 文本、fw filter 混合文本回读兼容和幂等故障冻结；v0.7.9 修复长周期 nft 到期单位；v0.7.10 增加默认关闭、无虚构账务的开发套餐绕过标记与空周期计量。生产节点仍须通过持久 journal 自动恢复并取得 applied ACK，不能据此宣称端到端协议健康。TCP 目标可达性与 UDP unknown 观测按当前 applied generation 授权存储。

## 尚未实现

真实 VPS/容量验收、合作端到端协议探针、商户激活与人工对账流程、生产离机恢复、已退役端口 conntrack 安全自动回收、Redis 与后续企业组网。节点应用日志/WAL 丢失后的人工重建流程仍需专门运维验收，不能自动清屏障或重置计量。生产服务器/域名/支付渠道由用户之后确定。

## 实施顺序

1. 已具备账户、规则、节点、成员/Key、配置分发、钱包套餐和支付连接器基础；继续保持回归与审查。
2. 已组合 Agent、tc、应用互斥、删除确认与目标可达性；继续完成真实生产路由/协议验收及安全退役端口回收。
3. 已实现逐规则、逐周期 WAL、重置/补传和去重；完成真实 offload/重传/计量差异与容量验收，不建立企业共享额度。
4. 商业闭环验收：真实支付、退款与对账、套餐续期和超额处置。
5. 运营验收：合作外部协议探测、签名通知接收方、成本凭据核对、工单与离机恢复。已完成对应基础功能不等于运营环境已验收。
6. 现有 1 家 VPN 服务商试点：真实传输、真实订单与账单、续费验证。
7. 客户有订单时拓展企业组网；后续多跳、上游防护、云骨干、专线和轻量 SD-WAN。

## 关键验收

- TCP/UDP/两者的传输、空闲重连、MTU、大包与小包 PPS。
- 端口竞争、规则修改、暂停既有流量、删除回收和配置失败回滚。
- 节点重启/失联、计数重置、重复/乱序事件、去重和用量缺口解释。
- 多规则独立额度及带宽、迟到报告周期归属、超额窗口、并发扣费、支付重复回调与退款。
- 外部探测、未知 UDP 健康、告警去重、备份恢复和租户隔离。
- 客户能完成付款、创建规则、收到入口、产生流量、看到账单并续费。

在节点资源与人员明确前，不将原讨论的 12 周视为已承诺工期。吞吐与 SLA 依据实际硬件和客户协议测试确定。
