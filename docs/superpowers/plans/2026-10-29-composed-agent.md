## 故障审查与验证

独立审查指出并修复：tc 校验失败应停流；WAL 身份必须绑定数据面，防止更换空目录重复计费；未 begin 的明确拒绝可退出旧 journal；回滚物理计划须先持久化，最终 Save 失败后才能继续识别计数。补充单元与真实容器故障回归，不以既有正常路径替代。

进一步复核修复重复恢复中断时的 actual+next plan 保留，以及环境检查超时后独立有界停流时间。新增 v17 升级重建完整快照，防止历史已校验快照缺少本地内核额度/到期参数。

实际容器测试已经覆盖真实 TCP/UDP、多包 forward 计数、外部表保护、已有和初始应用回滚、候选新端口存量流量隔离、WAL 周期归属、tc/nft/WAL 组合、配置替换不刷新额度、额度耗尽阻断，以及 Agent 不在线时内核到期阻断。最终追加 tc root 丢失及异 WAL 拒绝用例，证据以最终运行记录为准。

生产前置设置由节点运维核对：实际 ingress/SNAT、专用 egress 租约和 mark namespace、IPv4 forwarding、无 flowtable bypass、关闭 GRO/GSO/TSO/LRO。发布包不能替代这些环境证据，默认服务仍只校验。
