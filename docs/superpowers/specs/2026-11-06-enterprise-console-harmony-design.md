# 企业工作台信息架构与视觉统一设计

## 目标

把企业工作台从按技术组件拆分的页面，重组为按客户日常任务组织的扁平后台；减少重复入口，统一页面层级和视觉语言，同时保留现有真实状态、权限、支付、计量和交付边界。

## 已确认结构

左侧只保留五个一级入口，不使用展开菜单：

1. 运行概览
2. 转发规则
3. 入口节点
4. 套餐中心
5. 财务中心

右上角用户名打开单层账号菜单，直接进入企业协作、操作记录和支持中心；平台管理员额外看到平台管理，最后提供退出登录。账号菜单不包含二级菜单或标签导航。

## 页面归并

- 转发规则：保留规则管理，并把逐规则流量、入口资源和简化交付概况放在同一页面；客户看到交付结果，不暴露 generation checksum、租约令牌、证书摘要等平台内部事实。
- 入口节点：由原节点状态页演进，只展示当前企业规则关联节点的联系、配置、流量和资源样本。
- 套餐中心：包含套餐选购和当前规则套餐周期，不包含钱包流水。
- 财务中心：包含钱包余额、充值可用性和账本流水。
- 企业协作：从侧栏移入账号菜单，继续承载成员、邀请和 API Key。
- 支持中心：从侧栏移入账号菜单，继续承载告警和工单。
- 操作记录：从运行概览移入账号菜单，单独显示企业审计。
- 支付结算：仍是套餐购买流程中的临时路由，不进入任何菜单。

## 交互

- 用户名按钮显示头像首字母、邮箱和角色；点击后打开单层菜单。
- 点击菜单外、按 Escape、选择菜单项后关闭；Escape 关闭后焦点返回用户名按钮。
- 移动端保留抽屉式主菜单，账号菜单仍从页头打开。
- 未处理告警数量当前没有可靠的常驻前端聚合，不伪造角标；严重事实仍通过现有概览和支持数据表达。

## 视觉方向

- 保留深蓝侧栏，右侧使用浅灰白画布和白色内容面板。
- 使用系统无衬线字体、清晰的字号层级、统一 8–12px 圆角、细边框和克制的蓝色强调；不使用渐变、拟物或大面积阴影。
- 只有运行概览使用大号统计卡；业务页以页头、主要操作、筛选区、列表和次级信息区组成。
- 表格、表单、按钮、状态徽标、空状态和对话框使用统一间距与颜色，辅助小字满足 AA 对比度。

## 不改变的边界

- 不修改后端接口、数据库、计费、套餐购买、Agent、节点状态和权限判断。
- 不把 applied、节点在线或目标可达描述为端到端健康。
- 不修改平台管理后台 `/admin` 或独立登录页的结构。
- 不新增前端框架或第三方 UI 依赖。
